Weekly Petroleum Stocks Browser

A live view of EIA’s Weekly Petroleum Status Report “Stocks” table (psw09-2.xls) — crude oil and refined product inventories by grade and PADD, weekly only, pulled from the public Open Data API using your own free key.

Personal tool · not an official EIA product · built on EIA’s public Open Data API · fifth and final slice of the larger psw09-2 dataset (see project notes for the full 548-series assessment)
