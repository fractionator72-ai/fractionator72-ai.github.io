Natural Gas Browser

A proposed replacement for the natural gas half of the Petroleum and Natural Gas Navigator (DNAV) — all 53 API-backed series across all 7 EIA natural-gas route families, pulled live from EIA’s public Open Data API using your own free key. Every table here maps 1:1 to a confirmed api.eia.gov route — no PDF reports, microdata, Pipelines detail, or international series, which don’t have a standard API route (see project notes for the full assessment of what’s excluded).

Excluded from this build — no standard api.eia.gov route

~27 of the 80 human-facing series on data.php have no standard natural-gas API route at all — they’re microdata, reference tables, PDF reports, international data, or specialty products served outside the time-series API. The gap is roughly the difference between each category’s human-facing series count and its API leaf-route count; the items below are the ones specifically identified during the assessment, not necessarily an exhaustive list for every category.
