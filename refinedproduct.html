Weekly Refiner & Blender Net Production Browser

A live view of EIA’s Weekly Petroleum Status Report “Refiner and Blender Net Production” table (psw09-2.xls) — gasoline, jet fuel, and distillate output by grade, weekly and 4-week average, pulled from the public Open Data API using your own free key.

Personal tool · not an official EIA product · built on EIA’s public Open Data API · third slice of the larger psw09-2 dataset (see project notes for the full 548-series assessment)
